# The Solo Builder's Field Manual

Practical engineering with AI coding agents — grounded in evidence, not vibes.

## What's Here

- **[FIELD-MANUAL.md](FIELD-MANUAL.md)** — The guide. Universal practices for building software with AI coding agents, drawn from research, practitioner experience, and observed patterns across thousands of projects.
- **[STARTER-CLAUDE-MD.md](STARTER-CLAUDE-MD.md)** — A ready-to-use CLAUDE.md / AGENTS.md template to drop into new projects, with adaptation guides for different project types.

## Who This Is For

A software engineer (any level) working with AI coding agents to build software that other people will use. Agent-agnostic, stack-agnostic.

## Evidence Base

Every practice meets at least one bar: independently converged by multiple practitioners, empirically researched with data, or consistently observed across many projects. Opinions are labeled. Preferences are left out. Full sources cited in the manual.

Key sources include Anthropic's engineering research (~400K sessions), CodeScene's peer-reviewed code health studies, Simon Willison's Agentic Engineering Patterns, and Addy Osmani's practitioner workflow documentation.
